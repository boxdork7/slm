### 本次发现并修复的问题

`restore.sh` 原用 `grep -oP` 提取目标库名，在**非 UTF-8 locale** 下会直接失败：

```
grep: -P supports only unibyte and UTF-8 locales
[错误] 无法从备份文件中识别目标库名
```

已改用 POSIX `sed` 实现，去掉 PCRE 依赖。

> 这个问题只有真正跑一次恢复才会暴露 —— 光看脚本代码是发现不了的，
> 这也是「交付脚本」和「交付可用的备份能力」之间的差别。

### 结论

**通过。** 备份与恢复链路完整可用。
